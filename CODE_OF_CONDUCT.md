# Code of Conduct

This project is for people building and testing Go, baduk, weiqi, KataGo, and
AI-agent tooling. Contributions should be direct, technical, and respectful.

## Expected Behavior

- Be factual and specific when reporting problems.
- Assume good intent, but correct mistakes with evidence.
- Keep discussion focused on the code, docs, tests, and user workflows.
- Respect that contributors may have different Go strength, programming
  background, languages, and toolchains.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Dismissive comments about a contributor's Go rank, language, or experience.
- Publishing private SGF files, credentials, or personal data without consent.
- Repeated off-topic promotion or spam.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation
when behavior harms the project or its contributors.

Report conduct concerns through GitHub issue moderation tools or by contacting
the maintainers through the repository owner profile.
